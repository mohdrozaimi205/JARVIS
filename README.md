# JARVIS

Pembantu AI peribadi untuk Android, gaya Iron Man. Fasa 1: **Tab Taklimat**, iaitu taklimat pagi bersuara.

- Cuaca (MET Malaysia), IPU anggaran, mesyuarat hari ini dari kalendar telefon
- Kesihatan (Health Connect) dan cadangan pemakanan (Gemini)
- Berita Malaysia dan dunia
- Arahan suara: "good morning" dan "jarak dari Ipoh ke KL"

APK terbaru ada di **Releases**. Reka bentuk dan pelan ada dalam `docs/superpowers/`.
